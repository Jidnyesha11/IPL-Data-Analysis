# 🏏 IPL Data Analysis using Python

## 📌 Overview
This project performs Exploratory Data Analysis (EDA) on the Indian Premier League (IPL) dataset using Python.

The analysis focuses on player performances, team statistics, toss outcomes, match results, and winning patterns with the help of data visualization.

---

## 🚀 Features

- Data loading and preprocessing
- Exploratory Data Analysis (EDA)
- Top Man of the Match winners
- Toss winner analysis
- Batting first vs batting second analysis
- Team-wise winning statistics
- Histograms, Bar Charts, and Pie Charts
- Data visualization using Matplotlib & Seaborn

---

## 🛠️ Tech Stack

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset

- `matches.csv`

---

## 📊 Analysis Performed

- Dataset overview
- Top players with most Man of the Match awards
- Match result analysis
- Toss winner frequency
- Teams winning after batting first
- Teams winning after batting second
- Distribution of wins by runs
- Distribution of wins by wickets
- Team performance visualizations
